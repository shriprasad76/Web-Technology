# Mini Angular App

A small Angular project demonstrating:
- Components
- Services
- Routing
- Data binding

## Run locally
1. Open `mini-angular-app` in a terminal.
2. Run `npm install`.
3. Run `npm start`.

## Project structure
- `src/app/app.component.*` — root component and navigation
- `src/app/home/` — home page with simple binding
- `src/app/about/` — service usage example
- `src/app/data/` — data binding with event binding and template interpolation
- `src/app/app.service.ts` — shared service
- `src/app/app-routing.module.ts` — routing configuration
