# React Project 1

A very basic portfolio dashboard built with React and React Router.

## Run locally

1. Open a terminal in this folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

## Features

- Single-page application with React Router
- Sidebar navigation
- Four pages: Overview, About, Projects, Contact
- Simple, easy-to-read structure
